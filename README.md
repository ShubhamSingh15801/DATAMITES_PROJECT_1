The startup dataset was provided to me as part of the PRDA-01 Data Analytics Project Assignment.
The main purpose of this project was to analyse how different types of business expenditures affect startup profitability.
I performed data inspection and cleaning using SQL, Exploratory Data Analysis (EDA) using Python, and developed a Multiple Linear Regression model to predict startup profits.
I also created an interactive Power BI dashboard to present the findings through visualizations and key performance indicators.
